What it does

  • Scans the boards companies actually post onGreenhouse, Ashby, Lever and Workday, straight from their public endpoints. No key, no quota, no cost.
  • Scores what survives the filterClaude reads each role against a profile you write once, and says why it scored what it scored. It runs read-only and never writes a file.
  • Fills the applicationA Chrome extension fills the form from your profile and stops. You read it, you press submit.
  • Records what you sentIncluding which resume went out, so after thirty applications you can finally answer which version gets replies.
  • Reads your inbox and proposesConfirmations and rejections become suggested tracker updates, each citing the email it came from. Nothing is written until you approve it.

What it won't do

This is a tool that touches your job search and your resume. What it refuses to do matters as much as what it does.

  • It never submits an applicationIt fills the form and stops at the button. Tools that auto-submit send unreviewed screening answers, and a wrong salary figure reaches forty employers before anyone notices.
  • It never scrapes LinkedIn or GlassdoorBoth prohibit it, and the account at risk would be yours. Pay ranges come from the posting itself, where transparency laws increasingly require them.
  • It never decides on your behalfEvery status change from your inbox is a proposal that cites its source. The matcher once suggested rejecting an application at Ploy because an email arrived from Employ. That is why it proposes.
  • It never phones homeNo account, no telemetry, no server. The only requests it makes are to the job boards themselves.

Start

# look around with invented data
$ git clone https://github.com/jawnzzz/alyx && cd alyx
$ npm run demo
$ node src/track.mjs stats

# then make it yours
$ node src/seed.mjs --clear
$ cp config/boards.example.json config/boards.json
$ cp config/profile.example.md config/profile.md
$ npm run scan

Scanning needs only Node. Scoring needs the Claude Code CLI on your PATH. Both config files are gitignored, because they are yours.
